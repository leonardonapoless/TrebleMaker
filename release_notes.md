# TrebleMaker 1.0.1

## Installation Instructions

### macOS
1. Download `TrebleMaker_macOS_Installer.pkg`.
2. **Gatekeeper:** Since the installer is unsigned, macOS will block it by default. To install, **Right-click** (or Control-click) the `.pkg` file and select **Open**, then click **Open** again in the prompt.
3. Follow the installation wizard.

### Windows
1. Download `TrebleMaker_Windows_Installer.exe`.
2. **SmartScreen:** If Microsoft Defender blocks the installer, click **More info** -> **Run anyway**.
3. Follow the installation wizard.

### Linux
1. Download `TrebleMaker_Linux_Installer.zip`.
2. Extract the archive.
3. Open a terminal in the extracted folder and run the installer script:
   ```bash
   chmod +x installer_linux.sh
   ./installer_linux.sh
   ```
4. Follow the on-screen prompts.
